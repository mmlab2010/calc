# 스마트 밝은 테마 계산기 & 실시간 외폐/환율 계산기 구축 계획

시인성이 뛰어나고 직관적인 대형 버튼 디자인과 실시간 환율 연동(현금/송금 매매 조건별 환전) 기능을 탑재한 스마트 계산기 웹 애플리케이션을 제작합니다.

## 핵심 요구사항 반영 및 디자인 컨셉

1. **밝고 쾌적한 비주얼 디자인 (Light & Smart Glassmorphism)**
   - 가독성이 뛰어난 구글 폰트 (`Outfit`, `Noto Sans KR`) 적용.
   - 큼직하고 입체감이 느껴지는 소프트 둥근 버튼, 대비가 확실한 텍스트로 최고 수준의 시인성 확보.
   - 버튼 클릭 시 미세 애니메이션(Bounce/Press effect) 및 키보드 입력 완벽 지원.

2. **강력한 일반/스마트 계산기 기능**
   - 사칙연산, 백분율(%), 괄호, 백스페이스, 괄호 우선순위 및 실시간 수식 프리뷰.
   - 계산 기록 히스토리 (메모리 및 재사용 기능).

3. **특수 기능: 스마트 외폐/환율 계산기 (KRW, USD, JPY, CNY)**
   - **실시간 환율 연동**: 오픈 환율 API 연동 + 실패 시 실시간 백업 환율 제공 & 직접 환율 업데이트 가능.
   - **4가지 환전 거래 조건 지원**:
     - 💵 현금 살 때 (Cash Buy)
     - 💶 현금 팔 때 (Cash Sell)
     - 📤 송금 보내실 때 (Wire Send)
     - 📥 송금 받으실 때 (Wire Receive)
   - **환율 우대율 선택기 (Spread Discount)**: 0%, 30%, 50%, 80%, 90%, 100% 우대 옵션 제공 (실제 은행 환전 계산기와 동일한 정밀도).
   - **스마트 연동**: 계산기 결과를 클릭 한 번으로 환율 계산기에 대입하는 연동 버튼 제공.

---

## 제안하는 변경 사항 (파일 구조)

- `index.html`: 메인 웹 애플리케이션 구조 (계산기 디스플레이, 대형 키패드, 환율 모드 탭, 기록 모달/사이드바).
- `style.css`: 밝은 테마 반응형 CSS (디자인 시스템, 변수, Glassmorphism 패널, 큰 버튼 및 폰트 스타일, 애니메이션).
- `app.js`: 계산기 연산 로직, 실시간 API 환율 수집 및 우대율 적용 환전 계산 로직, 키보드 이벤트, UI 제어.

---

## 검증 계획

### 수동 및 기능 검증
1. **계산기 정확도 테스트**: 기본 사칙연산, 연쇄 계산, 괄호 연산, 백스페이스, C/AC 동작 검증.
2. **환율 계산기 테스트**:
   - KRW ↔ USD / JPY / CNY 간의 현금 살 때/팔 때, 송금 보내실 때/받을 때 계산 결과 검증.
   - 환율 우대율(예: 90% 우대)에 따른 수수료 차감/우대 정확도 확인.
3. **디스플레이 및 시인성 확인**: 큰 버튼, 가독성 높은 폰트, 반응형 화면(모바일/데스크톱) 시각 검증.
